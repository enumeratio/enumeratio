# Playground

Our toys — every page here is a live, interactive experience, not something to read. Nothing on this page lives
only here: each links to its real home, and this is just the curated index.

- **[CLI playground](/develop/packages/cli/playground)** — a real in-browser terminal running the actual
  `enumeratio` CLI grammar against the live core.
- **[Query](/explore/query/)** — write `WHERE`/`GROUP BY`/`ORDER BY` yourself, watch the table follow.
- **[Helmert projection](/develop/playground/helmert-projection)** — several polytopes (permutahedron, associahedron,
  hypercube, …) live in one shared coordinate space — orbit, zoom, toggle tessellations.
- **[Session demo](/develop/playground/session-demo)** — the cross-tab session client: run a query in one tab, watch it
  show up in another.
- **[Expression kitchen sink](/develop/packages/components/expression-examples)** and **[figure kitchen
  sink](/develop/packages/components/kitchen-sink)** — every worked example / every carrier's glyph, live,
  each one a self-checking demo.

Also worth a look: the style lab embedded on the [design system](/develop/contributing/design-system) page
switches every live component through five themes at once.
