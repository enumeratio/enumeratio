# Functions reference

::: warning Stub
Planned, not built — and blocked on a real design decision, not just docs work: there is no catalog of "shipped
math identities" to generate from today. An older `math_*` naming convention (`math_factorial`, `math_binomial`,
…) is explicitly retired in the codebase; what replaced it is per-collection engine functions (`fiber_*`,
`perm_*`, …), which aren't the same thing as a curated, citable list of named identities. Before this page can be
built, something has to decide what counts as "a shipped identity" and where it gets registered — then this
becomes one page per identity, same shape as the [collections reference](/develop/data/collections).
:::

Until that exists, [the API reference](/develop/api) documents the uniform generated surface every
collection shares, and [the bijections page](/learn/explorations/bijections) tours the registered `base_map`
identities specifically.
