# Docs

How to use enumeratio and notatio, and where to look things up.

## Learn

- [**Guides**](/guide/) — walkthroughs of the mathematics, one family of objects at a time,
  with live cells throughout.
- [**Explorations**](/explore/) — fewer words, more dials: one function per page, every
  constant on a slider.

## Look up

- [**Symbol reference**](/reference/symbol/) — every head, with examples that are also its
  tests. The [reference overview](/reference/) lists the rest: collections, statistics,
  maps, domains, formats and components.

## Tools

- [**Command line**](/docs/cli/) — `notatio` in a terminal: the REPL, one-shot evaluation,
  and pipes. Both run live in the browser: the [REPL](/docs/cli/repl) and the
  [command line](/docs/cli/command-line).
- [**Worksheet**](/worksheet/) and [**notebook**](/notebook/) — the two kinds of sheet.
- [**Playground**](/playground/) — every notatio component on its own page, for trying
  one out or embedding it in yours.
